# Code of conduct

Treat contributors and users with respect. Discuss the work and explain disagreements with evidence. Welcome people with different backgrounds and levels of experience.

Harassment, threats, discrimination, sexual content aimed at another person, and publication of private information are not acceptable. Do not use project spaces for spam or personal attacks.

Maintainers can edit or remove content, close discussions, or restrict participation to protect contributors. They should explain moderation decisions when it is safe to do so and apply these rules consistently.

For a conduct concern, use the repository's [private reporting route](SECURITY.md), if available. If no private route is available, ask for a private maintainer contact in a minimal issue without naming the affected person or posting sensitive details. Do not put conduct reports in public bug discussions.

This policy applies to project issues, pull requests, discussions, and other project spaces.
